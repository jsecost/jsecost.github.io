Automated Cell Quantification and Spatial Analysis in Microscopy Images

An applied computer vision pipeline developed to replace manual cell counting and measurement in an academic lab setting. The system automates cell detection, size proxy estimation, and spatial dispersion analysis across large batches of microscopy images, enabling scalable and consistent quantitative readouts where cells were previously counted by hand. The project emphasizes end-to-end tooling, practical validation, and quality control rather than novel segmentation methodology.

The approach uses deep learning–based object detection with post-processing to extract per-cell and per-well metrics, producing structured outputs suitable for downstream statistical analysis and experimental comparison.

Note: Bounding boxes were used as computationally efficient size proxies rather than exact cell boundaries. The system was designed for throughput, consistency, and relative comparison across conditions rather than pixel-perfect morphology.

Key Components:

- Automated detection of individual cells using deep learning–based object detection
- Extraction of per-cell size proxies from bounding box geometry
- Aggregation of per-image and per-well cell count statistics
- Spatial dispersion and density analysis across wells
- Batch processing of hundreds of microscopy images
- Filtering and validation of detections via size and confidence thresholds
- Generation of visual quality-control overlays for auditability
- Export of structured CSV outputs for downstream analysis
- Designed and implemented independently to replace manual lab workflows

Technologies / Methods:

YOLOv8 (object detection), Python, OpenCV, microscopy image processing, bounding-box–based size proxies, spatial statistics, batch image pipelines, data validation heuristics, visualization overlays, CSV-based data export.
